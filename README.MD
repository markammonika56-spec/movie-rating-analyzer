
# 🎬 Movie Rating Analyzer

## 📌 About the Project
Movie Rating Analyzer is a Python-based data analysis project that analyzes movie ratings and provides useful insights using Pandas and Matplotlib.

## 🎯 Objectives
- Analyze movie rating data.
- Calculate average movie ratings.
- Find the highest and lowest rated movies.
- Compare ratings by genre.
- Identify the best performing genre.
- Visualize data using charts.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## ✨ Features
1. Display all movies.
2. Calculate average rating.
3. Find highest rated movie.
4. Find lowest rated movie.
5. Calculate genre-wise average rating.
6. Identify best performing genre.
7. Generate bar chart.
8. Generate histogram.
9. Interactive menu-driven interface.

## 📊 Dataset Details

The dataset contains 10 movies with three columns:

- Movie: Name of the movie.
- Genre: Category of the movie.
- Rating: Movie rating out of 10.

## 🧹 Data Cleaning
- Identify missing values.
- Handle invalid ratings.
- Convert rating values into numeric format.
- Remove invalid records.
- Prepare clean movie data for analysis.

## 📈 Sample Results

- Total Movies: 10
- Average Rating: 8.23
- Highest Rating: 9.0
- Lowest Rating: 7.4
- Best Performing Genre: Action

## 📉 Data Visualization
The project uses:
- Bar Chart to compare average ratings by genre.
- Histogram to show movie rating distribution.
